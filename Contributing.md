# Contributing Guidelines

Thank you for your interest in contributing to the **Simple Interest Calculator** project!

We welcome contributions from everyone. Whether you are a beginner or an experienced developer, your participation can help improve this project.

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

You can contribute to this project in several ways:

- **Code Contributions:** Improve existing functionality or add new features.
- **Bug Reports:** Report errors, unexpected behavior, or issues in the application.
- **Bug Fixes:** Identify and fix existing problems in the Bash script.
- **Documentation Improvements:** Improve the README, installation instructions, examples, or other documentation.
- **Enhancements:** Suggest or implement improvements to the calculator's functionality, usability, and performance.
- **Ideas:** Share suggestions and new ideas that could make the project better.

## Getting Started

Follow these steps to contribute to the project.

### 1. Fork the Repository

Fork the repository to your own GitHub account using the Fork button on GitHub.

### 2. Clone the Repository

Clone your forked repository to your local machine:

```bash
git clone https://github.com/YOUR-USERNAME/Simple-Interest-Calculator.git
```

### 3. Navigate to the Project Directory

```bash
cd Simple-Interest-Calculator
```

### 4. Create a New Branch

Create a separate branch for your contribution:

```bash
git checkout -b feature/your-feature-name
```

### 5. Make Your Changes

Make the required modifications to the project.

Ensure that your code is readable, properly organized, and follows basic Bash scripting conventions.

### 6. Test Your Changes

Before submitting your contribution, test the application to ensure that:

- The script executes without errors.
- User inputs are handled correctly.
- Simple interest is calculated accurately.
- The total amount is displayed correctly.
- Existing functionality is not broken.

### 7. Commit Your Changes

Add and commit your changes:

```bash
git add .
git commit -m "Add: describe your changes"
```

### 8. Push Your Changes

Push your branch to your forked GitHub repository:

```bash
git push origin feature/your-feature-name
```

### 9. Submit a Pull Request

Open your forked repository on GitHub and create a Pull Request against the original repository.

Provide a clear description of the changes you have made and explain why they are useful.

## Reporting Bugs

If you discover a bug, please open an issue on GitHub.

When reporting a bug, include:

- A clear and descriptive title.
- Steps to reproduce the problem.
- Expected behavior.
- Actual behavior.
- Relevant error messages or screenshots, if available.

This information helps maintainers understand and resolve issues efficiently.

## Suggesting Enhancements

We appreciate suggestions that can improve the project.

When suggesting an enhancement, please provide:

- A clear description of the proposed feature.
- The problem it aims to solve.
- How the enhancement could improve the application.
- Any additional examples or references, if applicable.

## Code Guidelines

To maintain code quality, contributors should follow these guidelines:

- Write clean, readable, and well-structured Bash scripts.
- Use meaningful variable names.
- Add comments wherever necessary.
- Handle invalid user inputs appropriately.
- Avoid unnecessary code duplication.
- Test all changes before submitting a Pull Request.
- Keep documentation updated whenever functionality changes.

## Community Guidelines

All contributors are expected to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

We are committed to maintaining a respectful, inclusive, and collaborative development environment.

## Questions and Support

If you have questions, suggestions, or need assistance with contributing, feel free to open an issue in the GitHub repository.

We will do our best to help you.

## Thank You!

Thank you for taking the time to contribute to the **Simple Interest Calculator** project.

Every contribution, regardless of size, is valuable and appreciated.

Happy Coding!
